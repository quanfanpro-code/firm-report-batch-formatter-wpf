# 批处理互鉴需求

用户授权需求优先工作流、自主取舍实施并提交推送。落实比较中推荐的四项；本仓库负责识别纠正及检查记录，公文仓库负责过滤及取消。其余建议暂缓。

已厘清：使用者通过原 Windows 界面批量排版报告；短正文会因不足 200 字进入纯封面分支，需允许纠正。采用自动、纯封面、正文三种处理选择，默认自动沿用现行规则；正文仍独立检测是否含封面，不把两个概念混用。批次开始时固定选择。

每份结果保存实际错误、警告和既有门禁结果，批次保存已尝试文件及取消状态；取消后也保留记录。记录写入失败不改变已经成功的文档结果，明确提示。记录不冒充 Word 实测，不新增版式验证流程。

验收：手动正文能处理短正文，手动纯封面能覆盖长封面；默认自动及旧 HasCoverOverride 兼容；成功、失败、取消有独立记录且不覆盖已有记录。普通排版规则、金额处理、原稿保护不变。待确认项为空，用户已授权自主决策。
