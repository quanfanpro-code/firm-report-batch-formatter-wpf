# 批处理互鉴方案

选用最小方案：请求新增 nullable IsPureCoverOverride；分类器优先取明确选择，其余仍用现有阈值。HasCoverOverride 继续仅表示正文文档是否含封面。界面增加三项选择并在后台任务开始前快照。

记录直接序列化既有响应、门禁和日志事件，不再运行一套验证。DocumentPipeline.Run 包装原执行过程，保存单文件记录；GUI 收集本次响应并保存批次记录。记录使用新文件写入，发生冲突增加 GUID；写入异常只提示。明确 Word实测已执行=false。

替代方案：每份文件都弹确认窗口会增加日常操作；另建通用模板和审计框架会增加代码及依赖，均不采用。大批次仍按现有流程顺序处理。

验证使用少量真实最小 DOCX 检查分类分支与记录结果，修改完成后一次完整现有自动测试。仅 UI 控件增加，不重复 Word 排版实测。现有源文件先外部备份；回滚不改用户文档。不满足独立 ADR 的不可逆门槛。
