# 0001 缩进字段必须缇值与字符单位成对写

Word 的段落缩进同时存在两套字段：缇值（FirstLine 等）和字符单位（FirstLineChars 等）。当两者同时存在时，字符单位优先；而段落样式链上的字符单位缩进会"穿透"下来——段落只写缇值、不写字符单位时，样式（如 Normal 上的 FirstLineChars=200）仍然生效，把程序写入的缇值架空。2026-09 落款台阶塌平、章节标题被多缩进 2 字符，根因都在此。

决定：程序内任何写段落缩进的位置，必须成对显式写出两套字段（缇值与对应的字符单位值），不复位的字段显式清零。曾被否决的替代方案是清洗文档样式表里的字符单位缩进——那会改动用户文档的默认样式，影响面不可控。
